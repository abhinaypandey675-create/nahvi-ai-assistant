# Code of Conduct

## Our Commitment

NAHVI is an open repository for project evaluation, technical review,
learning, and discussion.

Everyone participating in the project is expected to communicate
respectfully and professionally.

## Expected Behavior

Participants should:

- Be respectful and constructive.
- Focus on technical discussion and project improvement.
- Provide useful and actionable feedback.
- Respect different opinions and approaches.
- Keep discussions relevant to the project.
- Avoid personal attacks or harassment.
- Respect intellectual property and project licensing terms.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, threats, or personal attacks.
- Discriminatory or hateful language.
- Deliberate disruption of project discussions.
- Publishing private or sensitive information.
- Sharing credentials, API keys, or other secrets.
- Attempting to compromise systems or accounts.
- Misrepresenting another person's work as your own.
- Using the repository to distribute malicious software.

## Security Issues

Please do not report security vulnerabilities through public issues.

Follow the instructions in `SECURITY.md` for responsible security
reporting.

## Project and License

Participation in discussions does not grant permission to copy,
redistribute, commercially use, or create unauthorized derivative works
from NAHVI.

The project's licensing terms are defined in `LICENSE.md`.

## Enforcement

The project owner may remove comments, discussions, pull requests,
or other contributions that violate this Code of Conduct.

Repeated or serious violations may result in restriction from
participating in the repository.

## Scope

This Code of Conduct applies to interactions within the NAHVI
repository, including issues, discussions, pull requests, and other
project-related communication.

## Contact

For concerns regarding conduct or project participation, contact the
project owner.
